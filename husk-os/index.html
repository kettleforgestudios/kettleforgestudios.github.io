Husk OS

Kettle Forge Labs

A lightweight, modular operating system for ESP32-S3 devices. Free, with public source code planned: a clean, simple core, plus optional free Nibs you add as you like. Every build is made for a specific device.

Available In development Last updated Nov 23, 2026 (Build 1)

Supported hardware

In development

Waveshare ESP32-S3-ePaper-1.54G V2

1.54-inch, 200 × 200 four-color e-paper display, two-button controls, Wi-Fi and device-specific firmware. Other ESP32-S3 boards may require different builds and hardware support.

Flash Husk OS over USB

Installs Build 1 on the Waveshare ESP32-S3-ePaper-1.54G V2. Flashing replaces the firmware and can reset saved settings. Check the board model before connecting.

Open this page in Chrome or Edge on a computer, or try Chrome on Android with USB host support. Connect the board with a USB data cable. If it doesn’t show up, unplug it, hold BOOT, and plug it back in.

USB flashing is unavailable in this browser. Use the ZIP download with a USB flasher. Open this page over HTTPS to flash over USB.

Husk OS downloads

Available

Build 1 for Waveshare ESP32-S3-ePaper-1.54G V2

Download Husk OS Build 1 (ZIP)

Includes a merged USB flash image and its SHA-256 checksum. Extract the ZIP and use the -USB.bin file with your USB flasher at offset 0x0. Use this image only on the Waveshare V2 board listed above.

Public source code is planned. Husk OS was previously called Lesion OS. Boards that still run Lesion OS get their updates from the separate Lesion OS update feed; new installs should use the Husk OS download above.

Nibs — optional add-on apps

Planned

Husk OS ships as a bare core. Nibs are small optional programs you add after installing it.

The first planned Nibs:

  • CatEars.nib: learns what your cat's meows mean and shows its best guess on the screen.
  • Zombie story.nib: a choose-your-path zombie story, played with the two buttons.
  • Weather.nib: current conditions and forecast on the e-paper screen over Wi-Fi.

Nibs are not available yet. Details will be shared once they have been built and tested on real hardware.
