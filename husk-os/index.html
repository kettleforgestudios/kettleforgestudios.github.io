Husk OS

A lightweight, modular operating system project for ESP32-S3 devices.

Husk OS is being developed as free, open-source software. The goal is a clean core system with optional, freely available apps and features that device owners can choose to install or build themselves.

In development

Supported hardware — initial target

Waveshare ESP32-S3-ePaper-1.54G V2

1.54-inch, 200 × 200 four-color e-paper display, two-button controls, Wi-Fi and device-specific firmware. Other ESP32-S3 boards may require different builds and hardware support.

Free downloads & source code

A clean public source release, verified device-specific firmware, installation instructions, and optional free apps are planned.

No public Husk OS firmware download is available yet. Do not flash firmware intended for a different board or hardware revision.

Planned

Nibs — optional add-on apps

Husk OS will ship as a bare core. Small optional programs, called Nibs, are planned so owners can add only the features they want after installing Husk OS.

Nibs are not available yet. Details will be shared once they have been built and tested on real hardware.

Upcoming Nib

Cat Ears

A planned free Nib that uses the board's microphone to learn what your cat's meows mean, such as food, door or attention, and shows its best guess on the e-paper screen. It can also play short sounds your cat learns to recognize.

Every cat develops its own meows, so Cat Ears learns one cat at a time; it doesn't claim to translate a universal cat language. Recordings stay on your device and your own computer, never in the cloud.

Project principles

  • Free and open-source core system
  • Free optional apps and features
  • Device-specific builds and clear compatibility instructions
  • Simple controls and an efficient e-paper interface
  • Community contributions welcome after the public source release
